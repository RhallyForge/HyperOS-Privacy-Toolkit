# Contributing

Contributions are welcome when they preserve the conservative safety model.

1. Do not submit personal device logs, raw UI dumps or unredacted screenshots.
2. Do not claim compatibility without physical-device evidence.
3. Keep analysis read-only by default.
4. Require exact confirmation for every mutation.
5. Document initial state, final state, persistence and restoration limits.
6. Do not add root, package uninstall, data clearing or protection bypasses.
7. Run the offline unit tests before opening a pull request.

See [Adding a compatibility profile](docs/adding-a-profile.md).
